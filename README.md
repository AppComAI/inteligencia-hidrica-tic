# Ciclo da Inteligência Hídrica

Simulação interativa do framework de apoio à decisão em quatro fases apresentado no artigo:

> **Inteligência Hídrica na Era Digital: O Papel das TIC e dos Sistemas de Apoio à Decisão na Governança de Recursos Hídricos**
> Carla Fabiana Mont-Morency Rosado Vieira; Sosthenis de Lima Timoteo; Ana Christine de Araújo Campos Koelfa (Cogerh).

- **Acesse a simulação:** https://appcomai.github.io/inteligencia-hidrica-tic/
- **Artigo completo (PDF):** [`Artigo_TIC_RH.pdf`](Artigo_TIC_RH.pdf)
- **DOI:** https://doi.org/10.5281/zenodo.23512968

A página (`index.html`, arquivo único) traz o fluxo das quatro fases, os cenários (operação normal, seca severa, cheia e alerta de segurança) e um jogo 3D com som e regras.

**Dados emulados, uso educativo.** Os números não representam reservatórios reais.
